# CHANTIER MANAGER

Application de gestion de chantiers (BTP) — clients, devis, dépenses, situations de travaux, équipe, matériaux, documents, rapports et trésorerie.

100% locale : les données sont stockées dans le navigateur (localStorage), rien n'est envoyé à un serveur. Installable comme application (PWA) et utilisable hors-ligne une fois ouverte au moins une fois avec une connexion.

Démo en ligne : https://amineabida-png.github.io/chantier-manager/
